# App/script/DebuggerManager.cpp

## Purpose

Implements the Studio script-debugging layer as DataModel instances: `DebuggerManager` (process singleton, parent of debuggers), `ScriptDebugger` (per-Script/ModuleScript attach point owning breakpoints and watches), `DebuggerBreakpoint` (line + enabled + condition), and `DebuggerWatch` (expression). Works by installing a combined lua hook (`DebuggerManager::hook`) on every thread of a debugged script and pausing coroutines via `lua_yield` from inside line hooks; watch/local/upvalue/global inspection is performed by resuming the paused thread back into the hook (`withPausedThread`) or, for watches, by evaluating "return <expr>" in a fresh eval thread whose environment metatable resolves names against the target frame's locals/upvalues/env.

## API

Flags: `FASTFLAGVARIABLE(LuaDebugger, false)`, `FASTFLAGVARIABLE(LuaDebuggerBreakOnError, false)`; constants sDebuggerManager/sScriptDebugger/sDebuggerBreakpoint/sDebuggerWatch; `static void checkDebugging()` throws "debugging is disabled" unless FFlag::LuaDebugger.

Special breakpoints (`ISpecialBreakpoint` subclasses with `hitTest(lua_State*, lua_Debug*)` and shared `baseThread`): `PauseNowBreakpoint` (any LUA_HOOKLINE), `StepInBreakpoint`, `StepOutBreakpoint` (call/ret depth counter ignoring C frames), `StepOverBreakpoint`.

Reflection surface: DebuggerManager — AddDebugger(script) [Security::None], EnableDebugging [LocalUser], read-only DebuggingEnabled, Resume/StepOver/StepIn/StepOut, GetDebuggers, events DebuggerAdded/DebuggerRemoved. ScriptDebugger — SetBreakpoint(line), GetBreakpoints, AddWatch(expression), GetWatches, GetWatchValue(watch), deprecated Resume/StepIn/StepOver/StepOut (throw "Depricated API - Use DebuggerManager::... instead"), GetStack, GetLocals(stackFrame)/GetUpvalues(stackFrame)/GetGlobals, SetLocal/SetUpvalue/SetGlobal(name,value[,stackFrame]); read-only Script prop ("read-only by design"), STREAMING ScriptPath, UI IsDebugging/IsPaused/CurrentLine; events EncounteredBreak(line), Resuming, BreakpointAdded/Removed, WatchAdded/Removed. DebuggerBreakpoint — read-only Line plus BoundProps line (STREAMING), IsEnabled, Condition; DebuggerWatch — Expression prop + CheckSyntax func.

Singleton: `static DebuggerManager& DebuggerManager::singleton()` via boost::call_once creating `Creatable<Instance>::create<DebuggerManager>()`.

DebuggerManager core: `setDataModel(DataModel*)` (rewires descendantAddedSignal, clears debuggers/unaddedDebuggers/lookup, reset()); `reset()`; `enableDebugging()`; `setBreakOnErrorMode(BreakOnErrorMode)` connecting `ScriptContext::scriptErrorDetected → onErrorSignal`; `findDebugger(lua_State*)` (lookup map keyed by L, falling back to RobloxExtraSpace script lookup with caching); `findDebugger(Instance*)`; `addDebugger_Reflection/addDebugger(Instance*)` (creates ScriptDebugger child); `addDebugger(shared_ptr<ScriptDebugger>)` parks in unaddedDebuggers until the script enters the DataModel (`addUnaddedDebuggerForAddedDescendant` accepts Script or ModuleScript); `populateForLookup(L, debugger)`; child add/remove bookkeeping firing debuggerAdded/debuggerRemoved and pruning pausedThreads (compares `isPausedThread(reinterpret_cast<uintptr_t>(iter->lock().get()))`); `onErrorSignal(L)` → debugger->handleError + errorThreads list; `pause/resume/stepOver/stepInto/stepOut`; `resume()` loop resumes each paused thread via `debugger->resumeThread(thread, evalLineHookForCurrentLine)`, handles Yield/Break-mode interplay, binds baseless specialBreakpoints to the yielded thread, resets them when the base thread completes or root thread resumes, swallows all exceptions (`catch (...) {}`); `static hook(L, ar)` routes LUA_HOOKCOUNT to `ScriptContext::hook` else `onHook`; `onHook` order: already-paused/handled check → ExecutionMode_Break pauses on any LUA_HOOKLINE → specialBreakpoint hitTest (after lua_getinfo "Sf") → user breakpoint via onLineHook; paused threads go to resumingPausedThreads (during resume) or pausedThreads.

ScriptDebugger core: ctor takes `Instance& script`, named "<script>Debugger"; `withPausedThread<R>(f)` — the key trick (citing lua-l 2012-06/msg00169): a paused thread has an unusable stack, so if it hasn't yielded yet (breakpointHookData set) f runs directly, otherwise a `hookFunction` is installed and the thread is resumed so f executes inside `withPausedThreadHook` at the line hook (which sets yieldCaptured and yields again); `debuggerBreak(L, ar)` records currentLine per event type, stores PausedThreadData{pausedLine, thread, callStack=getStack()} into pausedThreads[threadID], fires encounteredBreak(currentLine), then yields unless pausedThread was reset during the event; `onLineHook` skips one line after resume (currentLine>0 guard, DE8670-style), consults other debuggers when `hasDifferentScriptInstances(L)` (env-table pointer caching via prevFuncTable/prevRawScriptPtr/globalRawScriptPtr, reading "script" from LUA_ENVIRONINDEX); `shouldBreak(bp, L)` evaluates Condition by loading "return "+condition in a fresh eval thread under lua_pcall; `readLocals/readUpvalues/readGlobals` (lua_getlocal/lua_getupvalue loops filtering name[0]>0 and "(*temporary)"; globals iterated via lua_next over getfenv result with #if 0 alternate path); `traverseGlobals`+`populateFunctionName` reverse-map anonymous functions to global names by scanning the globals Table nodes directly (lstate/ltable internals); `readStack` builds FunctionInfo frames via lua_getinfo "nSlf" attributing scripts through getScriptForLuaState (reads env "script"); setLocal/doSetLocal via lua_setlocal, setUpvalue/doSetUpvalue via lua_setupvalue (strips tuple pushes), setGlobal via lua_setglobal; `handleError(thread)` captures error thread, extracts line from "file:N: msg" syntax-error format, records PausedThreadData.hasError and raises scriptErrorDetected(currentLine, errorMessage, stack); `resumeThread(thread, evalLineHookForCurrentLine)` no-ops for non-paused/error threads (resetting state), else clears pause state, fires Resuming, and either aborts the pending yield (breakpointHookData case) or `ScriptContext::getContext(thread).resume(thread, 0)`; `getScriptPath/setScriptPath` serialize identity as pipe-delimited child indices from DataModel plus "-"+requestHash validation (documented example block); `updateRootThread/forEachRefs` seeds rootThread from BaseScript::threadNode; `setLuaHook/updateHook` installs `DebuggerManager::hook` with mask LINE|CALL|RET|COUNT (+LUA_MASKERROR when BreakOnErrorMode_AllExceptions) over every thread reachable from rootThread's RobloxExtraSpace, only for matching scripts/module scripts; clone support via instanceClonedSignal → createClone copying breakpoints/watches.

Watch evaluation: `static int getIndexInfo(lua_State*)` — metatable-driven __index resolving keys as upvalue then local (via lua_getupvalue/lua_getlocal over stored frame/thread/"function"/"env"), falling back to env lookup or raw globals; `setIndexInfo` just logs; `setEvalThreadEnvironment(parentThread, evalThread, stackDepth)` builds the env table + metatable storing "frame"/"thread"/"function"/"env" and calls lua_setfenv on the loaded expression chunk; `DebuggerManager::readWatchValue(expression, stackDepth, L)` loads `"return "+expression` in a hook-less eval thread, applies the environment, lua_pcalls (failure → "*** Value not found ***"), converts via LuaArguments::get.

## Usage

Wired from App/script/ScriptContext.cpp: global `DebuggerManager()` function (FFlag::LuaDebugger gated) pushes the singleton; `evaluateStudioCommandItem` calls `DebuggerManager::readWatchValue`; `LuaInstanceBridge.cpp:callCallback` uses `findDebugger(callbackThread.get())` + `setIgnoreDebuggerBreak(true/false)` around callback resumes ("HACK: Make sure we don't yield while debugging"). ScriptContext::scriptErrorDetected feeds break-on-error. The hook replaces ScriptContext::hook entirely for debugged threads (LUA_HOOKCOUNT delegated back).

## Gotchas

- The whole mechanism depends on yielding from inside a debug hook (`lua_yield` in debuggerBreak / withPausedThreadHook) — legal in the patched 5.1 but a known Luau difference; grafting must rework pause/resume around Luau's interrupt/thread API.
- Threads are keyed by `reinterpret_cast<uintptr_t>(lua_State*)` throughout pausedThreads/currentThreadID maps.
- `resume()` swallows every exception (`catch (...) {}`), and error threads are resumed by having their resume call just reset debugger state.
- `shouldBreak` evaluates breakpoint conditions WITHOUT the frame-aware environment (plain fresh thread) — conditions see globals/env but not locals, unlike watches.
- getIndexInfo's frame arithmetic adds +2 when inspecting the main thread to skip the eval call and __index metamethod frames.
- readGlobals' #if 0 block documents an earlier stack-based approach; current code iterates the thread's fenv table directly.
- populateFunctionName reaches into internal Table node storage (sizenode/gnode/luaO_rawequalObj) to name anonymous functions — VM-internals coupling that breaks under any VM swap.
- ScriptDebugger::resume/step* deliberately throw deprecation errors while remaining registered reflection members.
- `ignoreDebuggerBreak` exists because engine-initiated callback execution cannot tolerate yields (see LuaInstanceBridge HACK note).
