# App/script/LuaInstanceBridge.cpp

## Purpose

Implements `Bridge<shared_ptr<Instance>, false>` — the userdata bridge whose metatable class name is `"Object"` — i.e., every Instance exposed to Lua. Provides `on_index`/`on_newindex` resolution order (property → yield function → function → event → child-by-name → camelCase retry), the Reflection-type-to-Lua-value marshaling tables (`pushLuaValue`/`assignLuaValue`), `Instance.new`, deprecated `Lock/Unlock`, member-function and yield-function invocation (`callMemberFunction`, `callMemberYieldFunction` + `YieldFunctionStateObject`), callback plumbing (`callCallback`, `callAsyncCallback`, `assignLuaCallback`), and the helper `newweaktable`.

## API

- `void RBX::Lua::newweaktable(lua_State *L, const char *mode)` — creates a table that is its own metatable with `__mode = mode`.
- `template<> const char* Bridge<shared_ptr<Instance>, false>::className("Object")`.
- `const luaL_reg ObjectBridge::classLibrary[] = { {"new", newInstance}, {"Lock", lockInstance}, {"Unlock", unlockInstance} }`.
- `int ObjectBridge::newInstance(lua_State*)` — `RBX::Name::lookup(name)` + `Creatable<Instance>::createByName(className, RBX::ScriptingCreator)`; optional parent arg via `ObjectBridge::getInstance(thread, 2)`, requiring Security::Plugin when the parent is `getRobloxLocked()`; returns pushed instance.
- `int ObjectBridge::lockInstance(lua_State*)` / `int ObjectBridge::unlockInstance(lua_State*)` — deprecated no-ops (push true / return 0).
- `static void pushLuaValue(RBX::Reflection::ConstProperty p, lua_State *L, RBX::Security::Context&)` — enforces descriptor security + scriptability, then dispatches on `desc.type == Type::singleton<T>()` for int, bool, float, double, ProtectedString (as string), std::string, shared_ptr<Instance>, G3D::Rect2D, PhysicalProperties, Vector3, Vector2, RbxRay, CoordinateFrame, Color3, BrickColor, UDim, UDim2, Faces, Axes, Region3int16, ContentId (string), NumberSequenceKeypoint, ColorSequenceKeypoint, NumberSequence, ColorSequence, NumberRange; `shared_ptr<const Instances>` becomes a Lua array table (empty table, never nil); enums push `EnumItem`; Ref properties push the Instance or nil; otherwise throws "Unable to get property %s, type %s".
- `static const char* PropertyNameCorrection(const shared_ptr<Instance>&, const char* name, lua_State*)` — maps lowercase "size" → "Size", logging a camelCaseViolation.
- `template<> int Bridge<shared_ptr<Instance>,false>::on_index(...)` — throws "The object has been deleted" for null; lookup order: property (`object->findPropertyDescriptor`, after `object->securityCheck`) → `YieldFunctionDescriptor` → `FunctionDescriptor` → `EventDescriptor` (Plugin permission when RobloxLocked) → child by name → uppercase-first retry reporting `camelCaseViolation` → callback descriptors error ("you can only set the callback value") → "%s is not a valid member of %s". Function/yield closures are created once per descriptor pointer and memoized in `LUA_ENVIRONINDEX` keyed by lightuserdata of the descriptor.
- `static void assignLuaValue(RBX::Reflection::Property p, lua_State *L, int index, RBX::Security::Context&)` — same type table for writes; ProtectedString written via `ProtectedString::fromTrustedSource(throwable_lua_tostring(...))`; PhysicalProperties accepts nil→default; SoundId/TextureId/MeshId/AnimationId properties accept strings converted to ContentId; enums accept EnumItem, integer, or string; Ref properties via `setRefValue`; else throw.
- `shared_ptr<Tuple> RBX::Lua::callCallback(Lua::WeakFunctionRef function, shared_ptr<const Tuple> args, boost::intrusive_ptr<WeakThreadRef> cachedCallbackThread)` — runs a sync callback on a cached child coroutine; contains a workaround loop for "a strange bug in Lua???" removing stray stack entries after `lua_newthread`; Yield → throws "Callbacks cannot yield"; Error → rethrows the Lua error string; Success → caches thread for reuse and returns result tuple read by file-local `readResults(...)`.
- `void callAsyncCallback(Lua::WeakFunctionRef, shared_ptr<const Tuple>, AsyncCallbackDescriptor::ResumeFunction, AsyncCallbackDescriptor::ErrorFunction, boost::intrusive_ptr<WeakThreadRef>)` with helpers `callAsyncCallbackSuccess`/`callAsyncCallbackError` — same pattern but Yield installs `Lua::Continuations` onto the coroutine so completion resumes it later through `ScriptContext::resume`'s continuation dispatch.
- `static void assignLuaCallback(RBX::Reflection::Callback, lua_State*, int index)` — permission check, nil clears the callback (`clearCallback`), else `lua_tofunction(L,index)` and binds `setGenericCallbackHelper` to callCallback/callAsyncCallback with a fresh cached-thread holder.
- `template<> void Bridge<shared_ptr<Instance>,false>::on_newindex(...)` — securityCheck, PropertyNameCorrection, then property write (special-casing `Instance::propParent`: RobloxLocked parents require Plugin, non-script-creatable classes throw "Cannot change Parent of type %s", uses `instance->setParent2(parent)`), else callback assignment, else "%s is not a valid member of %s".
- `int ObjectBridge::callMemberFunction(lua_State*)` — upvalue 1 is `const Reflection::FunctionDescriptor*`; enforces `desc->security`; missing self → "Expected ':' not '.' calling member function %s"; RobloxLocked instances under CoreGuiService require Plugin; `isMemberOf` check; `Kind_Custom` → `desc->executeCustom(instance, L)`; else `LuaArguments args(L, 1)` (skipping self), `desc->execute(instance, args)`, return `LuaArguments::pushReturnValue(args.returnValue, L)`.
- `class YieldFunctionStateObject : public boost::enable_shared_from_this<...>, boost::noncopyable` — fields `thread` (intrusive_ptr<WeakThreadRef>), `dm`, `instance`, `desc`, `L`, `callingThreadId`, `isExecuting`, `volatile int immediateResults` (sentinel `static const int YIELD = -1`), `reentrancyCheck`. `int execute()` calls `desc->execute(instance.get(), args, onReturnResult, onRaiseException)`; if no immediate return: sets `RobloxExtraSpace::get(L)->yieldCaptured = true` and `return lua_yield(L, 0)`. `onReturnResult(Variant)` pushes immediately when still on the calling Win32 thread (`GetCurrentThreadId()` comparison), else `scheduleResume(t, LuaArguments::convertToReturnValues(value))`. `onRaiseException(std::string)` throws inline when on the same thread, else `dataModel->submitTask(bind(&resumeThreadWithException, thread, message), DataModelJob::Write)`; static `resumeThreadWithException` prefers the thread's installed error continuation before falling back to `context->reportError(thread)`.
- `int ObjectBridge::callMemberYieldFunction(lua_State*)` — like callMemberFunction but for `YieldFunctionDescriptor*`, message "Did you forget a colon? ...", then constructs the state object and executes.
- `template<> int Bridge<shared_ptr<Instance>,false>::on_tostring(...)` — pushes `object->getName()`.

## Usage

This bridge is what makes the DataModel scriptable: registered per VM in `ScriptContext::openState` (`ObjectBridge::registerClass`, `registerClassLibrary`, `registerInstanceClassLibrary`); `game`/`workspace` globals are pushed via `ObjectBridge::push`. It leans on `Reflection::PropertyDescriptor/FunctionDescriptor/YieldFunctionDescriptor/EventDescriptor/CallbackDescriptor` lookups implemented in the reflection layer outside this module, marshals values through the atomic-class bridges (Vector3Bridge etc. defined under App/script/LuaAtomicClasses.cpp), events through `EventBridge` (App/script/LuaSignalBridge.cpp), and resumes threads exclusively through `ScriptContext::resume`.

## Gotchas

- Member-function closure memoization lives in `LUA_ENVIRONINDEX` (a Roblox-patched 5.1 concept — stock Lua has no per-thread environment table usable this way); keyed by raw descriptor pointer, so identical descriptors share one closure per thread and relational comparison of methods is stable.
- The Parent special case routes through `setParent2` (not `setParent`), checks RobloxLocked on BOTH old and new parent, and silently ignores no-op assignments; the `canSetParent` warning is commented out as spam.
- RobloxLocked gating is inconsistent by design: plain property/event/function access only requires Plugin when the instance is RobloxLocked, but functions are additionally exempted unless the instance descends from CoreGuiService ("a service we control").
- `on_index` tries children by name BEFORE the camelCase hack and before failing — so `part.Head` may resolve a child rather than a property, matching legacy behavior.
- `callCallback`'s stack-cleanup while-loop after `lua_newthread` documents an unexplained Lua quirk (comment: "This is because of a strange bug in Lua???") — worth preserving verbatim across any VM swap since behavior depends on exact stack layout.
- Sync callbacks cannot yield ("Callbacks cannot yield"); async callbacks can, via continuations. Both cache their worker coroutine only after a clean synchronous Success.
- `immediateResults` is volatile and the same-thread fast path compares Win32 `GetCurrentThreadId()` — this yield machinery assumes the DataModel thread identity is stable; a Luau graft must keep the "result arrived synchronously during execute" vs "arrived later" distinction intact.
- Duplicate dead code: two consecutive identical `if (desc.type==Type::singleton<shared_ptr<Instance>>())` blocks exist in assignLuaValue (second unreachable).
