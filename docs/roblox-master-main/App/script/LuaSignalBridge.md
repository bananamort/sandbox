# App/script/LuaSignalBridge.cpp

## Purpose

Implements the Lua surface of Roblox events: `RBXScriptSignal` (Bridge<EventInstance>, exposing `connect`/`Connect`, `wait`/`Wait`, deprecated `connectFirst`/`connectLast`) and `RBXScriptConnection` (Bridge<rbx::signals::connection>, exposing `disconnect()` and read-only `connected`). Contains the two slot classes that translate engine signal firings into script-thread resumes — `FunctionScriptSlot` (runs a connected callback in a cached child coroutine) and `WaitScriptSlot (one-shot resume of a thread that yielded inside `signal:wait()`) — plus `EventBridge::connect`/`EventBridge::wait` and `SignalConnectionBridge::disconnect`.

## API

- `template<> const char* Bridge<EventInstance>::className("RBXScriptSignal")`; `on_index(const EventInstance&, const char* name, lua_State*)` returns `EventBridge::connect` for "connect"/"Connect", also for "connectFirst"/"connectLast" (both require Security::LocalUser and warn "connectFirst is deprecated"/"connectLast is deprecated"), `EventBridge::wait` for "wait"/"Wait"; throws "Event:disconnect() has been deprecated. Use connection object returned by connect()" for "disconnect"; otherwise "%s is not a valid member". `on_newindex` always throws "%s cannot be assigned to". `on_tostring` specialization pushes `"Signal " + object.descriptor->name.toString()`.
- `class FunctionScriptSlot : public BaseScript::Slot` — members: `const Reflection::EventDescriptor* descriptor`, `ScriptContext& context`, `WeakFunctionRef function`, `WeakThreadRef cachedSlotThread`, `int executionDepth`, `bool useSubmitTask`, `weak_ptr<Reflection::TGenericSlotWrapper<FunctionScriptSlot>> weakSelf`, `weak_ptr<DataModel> weakDm`. Ctor `FunctionScriptSlot(const Reflection::EventDescriptor*, lua_State* thread, int functionIndex, bool useSubmitTask)`; `setWeakSelf(...)`; `operator()(const Reflection::EventArguments&)` — when useSubmitTask, marshals via `dm->submitTask(bind(&safeDoEventFire, weakSelf, arguments), DataModelJob::Write)`, else calls `doEventFire` inline; `doEventFire` implements the reentrancy-capped invocation described below.
- `class WaitScriptSlot : public BaseScript::Slot` — `WeakThreadRef waitThread`; `operator()` disconnects first ("Waits are one-shots"), optionally submitTask-marshals; `doEventFire` pushes arguments via `LuaArguments::pushValues(arguments, thread)`, `context.resume(thread, nargs)`, then unconditionally `lua_resetstack(thread, 0)`.
- `int EventBridge::connect(lua_State *L)` — gets `EventInstance&` from arg 1; connects only if source alive, `ei.descriptor->isScriptable()`, and `!space->context()->shouldPreventNewConnections()`; enforces `ei.descriptor->security != Security::None → requirePermission(security, name)`; validates arg 2 is a `Lua::WeakFunctionRef` (else error + printCallStack); computes `useSubmitTask = DFFlag::UseSubmitTaskWhenFiringSignalsOnSettings && source->useSubmitTaskForLuaListeners()`; builds the slot wrapper, `ei.descriptor->connectGeneric(source.get(), wrapper)`, `wrapper->slot.assignConnection(connection)`; always returns 1 with `SignalConnectionBridge::pushNewObject(L, connection)` (a disconnected proxy if connect was refused).
- `int EventBridge::wait(lua_State *L)` — same security/scriptable gating; installs a WaitScriptSlot connection on the current thread, asserts/sets `RobloxExtraSpace::get(L)->yieldCaptured = true`, returns `lua_yield(L, 0)`.
- `template<> const char* Bridge<rbx::signals::connection>::className("RBXScriptConnection")`; `on_index` serves "disconnect" (`SignalConnectionBridge::disconnect`) and "connected" (`lua_pushboolean(object.connected())`); throws otherwise. `int SignalConnectionBridge::disconnect(lua_State *L)` — `getObject(L, 1).disconnect(); return 0;`.

## Usage

Registered into every VM by `ObjectBridge::registerClass` / `EventBridge::registerClass` / `SignalConnectionBridge::registerClass` during `ScriptContext::openState`. Script-side `instance.SomeEvent:Connect(fn)` resolves through `LuaInstanceBridge` property lookup which produces an `EventInstance`, then this file's `on_index` hands out the C functions. Firing originates in the reflection event system (`Reflection::EventDescriptor::fireEvent` paths outside this module); slots call back into `ScriptContext::resume(ThreadRef,int)` per invocation and use `LuaArguments::pushValues` to marshal event argument tuples.

## Gotchas

- Thread caching: non-reentrant invocations reuse `cachedSlotThread` across fires, but any Yield or Error invalidates it (`cachedSlotThread.reset()`), and only a fully-Successful fresh thread is cached again — a yielding handler forces a new coroutine per fire.
- Re-entrancy guard: `executionDepth > 6` aborts the fire with "Maximum event re-entrancy depth exceeded for <Class>.<Event>" plus the offending function's source/line via `lua_getinfo(functionThread, ">S", &ar)` — note `>` consumes the function from the stack.
- If the WeakFunctionRef's owning thread died (`function.empty()`) the slot auto-`disconnect()`s itself mid-fire.
- The `useSubmitTask` path re-fires on the DataModel thread via `DataModel::submitTask(..., DataModelJob::Write)` holding only a weak self-reference — if the wrapper dies before the task runs the fire is silently dropped (`safeDoEventFire` locks weakSelf). Arguments are copied into the bind.
- `connect` never fails loudly at the Lua level: refused connections still return an RBXScriptConnection whose `connected` is false; the failure modes are the permission exception, or the not-a-function warning path.
- `EventBridge::wait` marks `yieldCaptured` so `ScriptContext::resume` won't queue a second waiter; resumption happens exclusively through `WaitScriptSlot::doEventFire`, and return values are discarded via `lua_resetstack(thread, 0)`.
- `shouldPreventNewConnections` (set by `ScriptContext::closeStates`) freezes new connects during shutdown while still returning a dead connection object rather than erroring.
