# App/humanoid/Humanoid.cpp

## Purpose

Implements `RBX::Humanoid`, the character controller Instance. This translation unit carries: the entire reflection surface (properties, events, bound functions, remote events); constructor defaults for all movement/health data; the movement pipeline (`calcDesiredWalkVelocity` and its `testWalkSpeed` security call site); walk-mode/click-to-walk; tool equipping with network split; character/joint construction (R6 Motor6Ds, R15 RigAttachments); appendage cache maintenance; the IStepped simulation driver (`onStepped` → simulate/noSimulate); KernelJoint lifecycle (`CheckTorso`, world entry/exit); billboard name/health rendering; first-person transparency and rotation; status management; Animator proxying; and platform-network floor bookkeeping.

## Usage

Implements Humanoid.h. The class is the IStepped/KernelJoint hub of the humanoid FSM: every frame `onStepped` decides simulate-vs-noSimulate, HumanoidState mutates `currentState` in place, and `fireEvents` emits the reflected state signals consumed by scripts. Transition triggers are owned by the STATE_TABLE in [HumanoidState.cpp](HumanoidState.md); this file contributes three control paths into it:

1. `changeState(StateType)` from Lua/`ChangeState` → sets the pending luaState honored at the top of `doSimulatorStateTable`.
2. Reflected booleans (Jump/Sit/PlatformStand/Strafe/walk inputs) that become JUMP_CMD/SIT_CMD/etc. events.
3. `setStateTransitionEnabled` gating which table exits are legal.

## Gotchas

- **Speed-hack tripwire (task-flagged): CONFIRMED with precise mechanics.** `testWalkSpeed` itself is defined inline in Humanoid.h (lines 371–382): `walkSpeedErrors` increments when `walkSpeed > walkSpeedShadow` and resets to 0 otherwise; `> 8` consecutive over-shadow writes OR `fabs(percentWalkSpeed) > 1.01` fires `Security::setHackFlagVs<LINE_RAND4>(hackFlag11, HATE_SPEEDHACK)`. The .cpp confirms the single call site (`calcDesiredWalkVelocity`, line 1174) and why legit writes never trip: `setWalkSpeed` mirrors the shadow on every engine-side write, and `setPercentWalkSpeed` clamps to [0,1] so only direct memory tampering can exceed 1.01.
- `StringConverter<HUMAN::StateType>::convertToValue`: any unrecognized text falls into `if(text.find("None"))` — `std::string::find` returns npos (truthy) when absent, so unknown strings silently convert to state `xx` rather than failing. Same npos-truthiness pattern makes any garbage convert to NAME_OCCLUSION_ALL / POISON_STATUS in those converters.
- `previousState` initializes to FREE_FALL (not a sentinel) — first fireEvents treats the humanoid as having exited freefall.
- Torso/LeftLeg/RightLeg setters are empty stubs ("deprecated, but can be called by LUA") despite being registered reflection writers.
- `getCamearaOffset` misspelling is API surface (bound reflection getter) — cannot be renamed without breaking the property binding.
- Non-owned humanoids simulate only on long steps (`event.longStep`); owned-by-local-player humanoids ignore longStep and use full gameStep dt.
