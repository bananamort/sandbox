# util/Memory.h

## Purpose
One-line forwarding header: includes `rbx/memory.h`. All actual memory-allocation utilities live there (outside util/).

## Declared API
```cpp
#include "rbx/memory.h"
```
(Note: no `#pragma once` of its own — relies on the included header's guards.)

## Gotchas
- Include `rbx/memory.h` directly for clarity; this shim exists presumably for include-path compatibility.
