# App/include/v8datamodel/PartInstance.h

## Purpose

`PartInstance` — the core physical part: PVInstance subclass binding the reflection instance to a V8World `Primitive` (position/velocity/contacts live engine-side), plus graphics link (`GfxPart`), surfaces, material/color/transparency state, network ownership + interpolation, touch signals, resize/grid logic, and camera-subject behavior. Nearly every concrete part class derives from it. Also defines the on-demand `OnDemandPartInstance` extension block and the `TouchedSignal` wrapper.

## Gotchas

- Canonical split-brain storage: physics state (size/CF/vel/friction/elasticity) lives in the `Primitive`, appearance in PartInstance fields, signals in the on-demand block — reading "the part" means picking the right accessor (`getTransparencyXml` vs `getTransparencyUi`).
- Transparency UI formula composes localTransparencyModifier multiplicatively; >0.1f threshold decides transparent rendering path.
- TouchedSignal slots keep a weak back-ref and bump an atomic count per connection — disconnect ordering matters; deprecatedStoppedTouchingSignal is explicitly deprecated in-name.
- `raknetTime` is a public float jammed onto every part for network use ("judiciously").
- Anchor/unanchor goes through gather/update ownership-data pairs — custom code touching anchoring must preserve that sequence or network-ownership resets break.
- Default FormFactor from base is always SYMETRIC; subclasses (FormFactorPart family) override.
