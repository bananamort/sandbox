# App/include/v8datamodel/UserInputService.h

## Purpose

`UserInputService` — INTERNAL_LOCAL creatable service: the central input hub translating platform events (keyboard/mouse/touch/gesture/gamepad/motion/VR) into InputObjects and signals, buffering cross-thread event queues under per-category mutexes, driving local-character movement/jump/camera manipulation, mouse icon stack + wrap/lock modes, TextBox focus plumbing, gamepad connectivity/keycode tables, and modal/emulation toggles.

## Gotchas

- Two lock disciplines coexist: fireInputEvent takes the DataModel lock; dangerousFireInputEvent REQUIRES the caller to hold it — mixing them up deadlocks or races (both documented in-header).
- processedMouseEvent carries a raw `void*` native event handle to listeners.
- The five category mutexes + static InputEventsMutex mean input state is touched from multiple threads — ordering between buffer drain and DataModel processing matters.
- fakeMouseEventsMap synthesizes mouse events from touch for legacy GUI compatibility — double-delivery possibilities.
- Platform enum includes joke entries (DOS, BEOS, OUYA, CHROMECAST).
