# App/include/humanoid/Humanoid.h

## Purpose

Declares `RBX::Humanoid`, the character controller Instance: a DescribedCreatable that is simultaneously a `KernelJoint` ("Implements computeForce"), IAdornable (name/health billboards), ICharacterSubject (camera follow), IModelModifier, and IStepped. Owns the current `HUMAN::HumanoidState`, all reflected movement/health data (walk speed, jump power, health, seat, rig type...), appendage caches, tool equipping, platform-networking floor bookkeeping, animation proxying to `Animator`, and speed-hack detection (`testWalkSpeed` → hackFlag11/HATE_SPEEDHACK).

## Gotchas

- Speed-hack tripwire: `walkSpeedShadow` mirrors walkSpeed server-side; >8 consecutive over-shadow writes OR |percentWalkSpeed| > 1.01 sets hackFlag11 — instrumentation touching these paths will false-positive HATE_SPEEDHACK.
- `getCamearaOffset` misspelling is API surface.
- Compacted Vector3 conventions (walkDirection z-in-y) are easy to misread at call sites.
- Dangerous/Slow/Fast accessor split: Fast uses appendageCache (must be kept fresh by sibling listeners), Slow walks the tree every call, Dangerous returns possibly-stale pointers for reflection only.
- breakJointsOnDeath requires BOTH ever-had-neck AND ever-had-health — humanoids built without a neck never break joints on death.
