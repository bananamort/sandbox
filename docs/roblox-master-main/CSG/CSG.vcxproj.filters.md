# CSG.vcxproj.filters

## Purpose

VS solution-explorer filter metadata for CSG.vcxproj. Purely cosmetic: two filters ("Source Files", "Header Files", stock GUIDs/extensions) mapping `CSGKernel.cpp` → Source Files and `CSGKernel.h` → Header Files. No build semantics.

## API / Usage / Gotchas

N/A — consumed by Visual Studio only. BOM-prefixed UTF-8 (`\ufeff`). Keep in sync if files are added to CSG.vcxproj.
