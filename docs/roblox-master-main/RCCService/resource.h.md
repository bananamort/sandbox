# resource.h

Source: `roblox-sandbox/RCCService/resource.h` (16 lines)

## Purpose

Visual Studio resource-script include generated by the RC editor; pairs with `RCCService.rc`. Defines the single icon resource identifier used by the service binary.

## API

```cpp
#define IDI_ICON1   101
// APSTUDIO next-value bookkeeping:
#define _APS_NEXT_RESOURCE_VALUE  103
#define _APS_NEXT_COMMAND_VALUE   40001
#define _APS_NEXT_CONTROL_VALUE   1001
#define _APS_NEXT_SYMED_VALUE     101
```

`//{{NO_DEPENDENCIES}}` marker tells the IDE not to regenerate dependencies.

## Usage

Included only by `RCCService.rc`; `IDI_ICON1` references `icon1.ico` (the service's Explorer/event-log icon).

## Gotchas

- Purely machine-maintained; edit through the VS resource editor, not by hand.
- No string table/version block here — version info comes from the `VersionInfo` resource declared in `RCCService.rc`.
