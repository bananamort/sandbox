## Purpose

gSOAP import stub for **WS-Addressing 2005/08** (`http://www.w3.org/2005/08/addressing`) — the W3C-final WS-Addressing revision and the newest of the four `wsa*` stubs in this import set. Generated by `wsdl2h -cgye` from `WS-Addressing05.xsd`, modified by Robert van Engelen (import-not-copy namespace, `#define SOAP_WSA_2005`, removal of the duplicate `xsd__boolean`). Vendored toolchain material; not used by RCCService's WSDL.
