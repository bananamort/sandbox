# wsa.h

Source: `roblox-sandbox/RCCService/gSOAP/import/wsa.h` (255 lines)

## Purpose

gSOAP import stub for **WS-Addressing 2004/08** (`http://schemas.xmlsoap.org/ws/2004/08/addressing`) — the revision the README lists as the canonical `wsa.h`. Generated by `wsdl2h -cgye` and adjusted by Robert van Engelen to import (not copy) the namespace. The header's long comment block doubles as a mini-tutorial: it shows exactly how to declare a WS-Addressing-aware `SOAP_ENV__Header` and how client/server code populates and consumes those headers. Vendored toolchain material; not used by RCCService's WSDL.
