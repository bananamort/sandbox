## Purpose

Generated by `wsdl2h -cgye`, then modified by Robert van Engelen to import the namespace and add `#define SOAP_WSA_2004` for plugin version dispatch. Structurally a near-copy of `wsa3.h` with revision-specific enums. Vendored toolchain material; not used by RCCService's WSDL.
