# WindowsClient/Application.cpp

## Purpose

Implementation of `RBX::Application` — the join orchestrator. Contains: AppSettings.xml consumption (`LoadAppSettings`, incl. BaseUrl), command-line parsing (`ParseArguments`), the full `Initialize` anti-tamper + network sequence, the two join paths (direct joinScriptUrl vs PlaceLauncher polling via `LaunchPlaceThreadImpl`), game/teardown (`StartNewGame` / `InitializeNewGame` / `Teleport` / `Shutdown`), crash/log handling, single-instance enforcement, video-pre-roll window-show gating, and in-game browser wiring. This is the primary file for harness interception of "process start → place joined".

## API

Key symbols and real signatures:

- `Application::Application()` — logManager("Roblox",".Client.dmp",".Client.crashevent"), launchMode=Play, spawns `logsCleanUpHelper` thread (deletes RBX*.log older than 3 days from tmp path and %LOCALAPPDATALOW%\RbxLogs).
- `bool Application::LoadAppSettings(HINSTANCE hInstance)` — GetModuleFileNameW → SetCurrentDirectoryW(exe dir) → TextXmlParser over `<exeDir>\AppSettings.xml`; calls `fixExceptionsThroughKernel()`; registry CrashReport DWORD → crashReportEnabled; SilentCrashReport XML-default-1 then registry override → `RobloxCrashReporter::silent`; **BaseUrl**: trailing-`/` normalized then `SetBaseURL(valBaseUrl)`; ContentFolder → `ContentProvider::setAssetFolder`; HideChatWindow → hideChat. Returns false on any exception (→handleError→exit).
- `bool Application::ParseArguments(const char* argv)` — options: `help/?`, `globalBasicSettingsPath|g <path>`, `version|v`, `id <int>`, `content|c <dir>`, `authenticationUrl|a <url>`, `authenticationTicket|t <str>`, `joinScriptUrl|j <url>`, `browserTrackerId|b <id>`, `waitEvent|w <name>`, `API <file>` (dumps reflection metadata, returns false), `dmp|d` (upload crash dumps, returns false), `play`, `app`, `fast`; debug-only: `userName`, `passWord`, `md5 <hash>` (spoofs DataModel::hash). No args or help → MessageBox with options text, return false. **Obfuscated `-w` channel**: `atoi(waitEventName) % 0x01234567 == 0x0BADC0DE % 0x01234567 && ... % 0x89ABCDEF` (= decimal 195936478) → `protectVmpSections(); RBX::Security::patchMain(); return false;` — the golden-hash release patcher; `-w 10558381` (=0x00A11BAD) → silent `return false`. `--play` sets launchMode=SharedLauncher::Play.
- `bool Application::Initialize(HWND hWnd, HINSTANCE hInstance)` — ordered sequence:
  1. Analytics reporter identity ("PC Player", geo, file version); `initializeLogger()` (StandardOut→OutputDebugString bridge); `Game::globalInit(false)`; optional debug `loginAsync(userName,passWord)` POST to `{BaseURL w/ https+api}login/v1` (blocking wait).
  2. Optional inferred-crash thread (DFFlag WindowsInferredCrashReporting): reads/writes registry InferredCrash marker.
  3. **Join URL determination**: if `vm.count("id")` → `requestPlaceInfo(id,...)` builds `{GetBaseURL()}Game/PlaceLauncher.ashx?request=Request&placeId=%d&isPartyLeader=false&gender=&isTeleport=true` and polls; failure ⇒ return false. Else if auth triple present in cmdline → use them; sets Stats/TeleportService browserTrackerId; lowercased `joinScriptUrl` containing `"placelauncher.ashx"` ⇒ `launchMode = Play_Protocol`, `scriptIsPlaceLauncher=true`.
  4. Futures kicked off concurrently: `renewLoginAsync(authenticationUrl, authenticationTicket)` (if login future invalid) and — unless place-launcher mode — `fetchJoinScriptAsync(scriptUrl)` (file-static: only if `ContentProvider::isUrl && Network::isTrustedContent`, else empty future "silent error is harder to hack"; success path is `HttpAsync::getWithRetries(url,5)`).
  5. Anti-tamper block: `CollectMd5Hash(moduleFilename)`→DataModel::hash (unless spoofed); `vmProtectedDetectCheatEngineIcon()`; `RBX::isSandboxie()`; initial `ProgramMemoryChecker().getLastCompletedHash()` into `pmcHash.nonce`; `LuaSecureDouble::initDouble()`; `protectVmpSections()` (de-RWX .vmp sections, returns size diff); dynamic `SetProcessDEPPolicy(1)`; `FLog::ResetSynchronizedVariablesState()`.
  6. HTTP backend lottery: `rand()%100 < GetValueHttpUseCurlPercentageWinClient()` decides curl vs WinInet; if !curl, re-issues renewLoginAsync after `Http::SetUseCurl(false)`; `Http::SetUseStatistics(true)`.
  7. Settings load: `GlobalAdvancedSettings::singleton()->loadState("")` (unless DebugUseDefaultGlobalSettings), `GlobalBasicSettings::singleton()->loadState(globalBasicSettingsPath)` under `Security::Impersonator(RobloxGameScript_)`.
  8. `#if !RBX_STUDIO_BUILD`: `hookApi()` (robloxHooks.cpp), `vehHookLocationHv = (uintptr_t)vehHookLocation`, `vehStubLocationHv = &RtlDispatchExceptionHook`, `setupCeLogWatcher()`.
  9. `initializeCrashReporter()` (WriteCrashDump, DumpErrorUploader wired to `GetDmpUrl(GetBaseURL(),true)`); cheat-engine/sandboxie flags OR'd into `DataModel::sendStats` / Tokens (`HATE_CHEATENGINE_OLD`, `HATE_INVALID_ENVIRONMENT`) in release configs.
  10. `setWindowFrame()` (misleading name): release-only `VerifyCryptSignature(moduleFilename)`; mismatch prints decoy error "Important !Loading shader files" and sets `HATE_SIGNATURE`.
  11. `uploadCrashData(false)` (uploads prior-run dumps per DebugSettings Prompt/Report); `shareHwnd(hWnd)` publishes HWND via named file mapping `RBXMAINWND-4DAAC10B-9C9A-4471-9218-07310329FD0D`; single-instance thread `waitForNewPlayerProcess` (named event `ROBLOX_singletonEvent` + mutex `ROBLOX_singletonMutex`; a second instance posts WM_CLOSE to this one); ProfanityFilter::getInstance(); Profiler "Main"; TaskScheduler thread count; Google-Analytics lottery init; `postMachineConfiguration(GetBaseURL(), lastGFXMode)`; TaskScheduler add `VerifyConnectionJob`.
  12. Branch: non-protocol → **`StartNewGame(hWnd, joinScriptResult, false)`** then `authenticationResult.wait()`; protocol → `InitializeNewGame(hWnd)`, `SetUiMessage("Requesting Server...")`, `authenticationResult.wait()`, `Stats::reportGameStatus("AcquiringGame")`, spawn `launchPlaceThread` → `LaunchPlaceThreadImpl(scriptUrl)`.
  13. `marshaller = FunctionMarshaller::GetWindow(); teleporter.initialize(this, marshaller);`
  14. `doMachineIdCheck` background thread — machine ban ⇒ marshaller->Execute(AboutToShutdown)+Execute(Shutdown)+MessageBox+WM_CLOSE.
  15. Sets named event `www.roblox.com/robloxStartedEvent` (non-protocol only here; protocol path sets it in waitForShowWindow).
  16. Pre-roll show-window thread `waitForShowWindow(delay)` where delay = `GetValueVideoPreRollWaitTimeSeconds()*1000` when `GetValueAllowVideoPreRoll() && !waitEventName.empty()` else 0; optional bootstrapper-version validation thread (`ValidateLauncherPercent` lottery).
- `RequestPlaceInfoResult Application::requestPlaceInfo(const std::string url, std::string& authenticationUrl, std::string& ticket, std::string& scriptUrl) const` — GET (or POST when FFlag PlaceLauncherUsePOST); `WebParser::parseJSONTable`; JSON fields `status` (2=SUCCESS w/ `authenticationUrl`,`authenticationTicket`,`joinScriptUrl`; 6=GAME_FULL; 10=USER_LEFT; 0/1=RETRY; other=FAILED).
- `bool Application::requestPlaceInfo(int placeId, ...)` — builds PlaceLauncher URL, retries `FInt::RequestPlaceInfoRetryCount`(5) times sleeping `FInt::RequestPlaceInfoTimeoutMS`(2000).
- `void Application::LaunchPlaceThreadImpl(const std::string& placeLauncherUrl)` — polling loop over requestPlaceInfo(url-form); SUCCESS ⇒ `fetchJoinScriptAsync(joinScriptUrl)`, connects `currentDocument->startedSignal → onDocumentStarted`, then `datamodel->submitTask(boost::bind(&Document::Start, currentDocument.get(), joinScriptResult, launchMode, false, getVRDeviceName()), DataModelJob::Write)` — **the submit that actually joins**; GAME_FULL/USER_LEFT set UI messages; final FAILED ⇒ "Failed to request game, please try again."
- `void Application::StartNewGame(HWND hWnd, HttpFuture& scriptResult, bool isTeleport)` — new Document → Initialize(hWnd,!hideChat); new View unless teleport; `mainView->Start(game)`; connect startedSignal; submitTask(Document::Start(...)) Write job; wire GuiService `openUrlWindow`→openUrlInBrowserApp and `urlWindowClosed`→closeBrowser; initVerbs().
- `void Application::InitializeNewGame(HWND hWnd)` — same minus script submit (used before protocol launch thread).
- `void Application::Teleport(const std::string& authenticationUrl, const std::string& ticket, const std::string& scriptUrl)` — runs on UI thread (marshalled by Teleporter): PrepareShutdown → mainView->Stop() → shutdownVerbs → document Shutdown+reset → optional ReloadSettingsOnTeleport settings prune → fresh renewLoginAsync + fetchJoinScriptAsync → StartNewGame(mainWindow, joinScriptResult, true) (view preserved).
- `void Application::AboutToShutdown()` — enteredShutdown CAS; Document::PrepareShutdown (kills hung scripts); View::AboutToShutdown (remember window placement).
- `void Application::Shutdown()` — shutdownVerbs; mainView Stop+reset; stop/join singleton + show-window threads; currentDocument Shutdown+reset; GlobalBasicSettings saveState (Advanced deliberately NOT saved, DE7393); Game::globalExit(); FunctionMarshaller::ReleaseWindow; registry InferredCrash=0.
- Helpers: `waitForShowWindow(int delay)` — opens `waitEventName` event, mutes SoundService while waiting, then `mainView->ShowWindow()` + sets robloxStartedEvent; `validateBootstrapperVersion()` — compares RobloxPlayerLauncher.exe version to FInt BootstrapperVersionNumber(51261), downloads replacement from `http://setup.<www-domain>/...`; `onMessageOut`; `handleError`; `uploadCrashData`; `doOpenUrl/doCloseBrowser/openUrlInBrowserApp/closeBrowser` (RbxWebView lifecycle on UI thread); `onDocumentStarted(bool)` (ClientLaunch influx report); `getVRDeviceName()`.

FastFlags/Ints defined here: ReloadSettingsOnTeleport(false), DebugUseDefaultGlobalSettings(false), RwxFailReport(false), FInt ValidateLauncherPercent(0)/BootstrapperVersionNumber(51261)/RequestPlaceInfoTimeoutMS(2000)/RequestPlaceInfoRetryCount(5)/InferredCrashReportingHundredthsPercentage(1000); DFFlags DontOpenWikiOnClient, WindowsInferredCrashReporting, DFInt JoinInfluxHundredthsPercentage; imports GoogleAnalyticsTrackingEnabled, PlaceLauncherUsePOST.

## Usage

The complete start-to-place sequence for the harness: `_tWinMain` → LoadAppSettings (BaseUrl set) → ParseArguments → FetchClientSettingsData → CreateWindow(hidden) → Initialize steps 1–16 above → Document::executeScript on the DM write queue → either `game->configurePlayer(...)` (payload-after-CRLF starts '{') or `ScriptContext::executeInNewThread(COM, verifiedSource, "Start Game")`. To drive a local join: serve AppSettings BaseUrl locally, pass `--authenticationUrl/-a --authenticationTicket/-t --joinScriptUrl/-j` (non-placelauncher URL fetches the script directly), or `--id N` to exercise PlaceLauncher polling.

## Gotchas

- `fetchJoinScriptAsync` returns an *empty* future for URLs failing the trust check — join later fails inside executeScript with a generic UI message, not an error here.
- The `case FAILED:` in LaunchPlaceThreadImpl falls through into RETRY's Sleep (deliberate retry-with-backoff).
- `-w 195936478` rewrites the exe on disk (patcher mode) and exits; never combine with normal play args.
- requestPlaceInfo(int) sleeps even after the final attempt; protocol mode keeps GAME_FULL polling until retries exhaust.
- `shareHwnd` mapping size is `sizeof(HWND)` (pointer-sized) — 32-bit build assumption.
- `loginAsync` rewrites http→https and www→api in the URL string unconditionally.
