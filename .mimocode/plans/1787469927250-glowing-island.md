## Changes

### 1. `.github/workflows/build.yml` — add smoke-run step (windows-build job)
After "Collect binaries", before "Upload artifacts":

```yaml
      - name: Smoke-run RCCService -Console
        shell: pwsh
        timeout-minutes: 3
        run: |
          $exe = Get-ChildItem -Recurse -Include RCCService.exe | Select-Object -First 1
          if (-not $exe) { Write-Error "RCCService.exe not found"; exit 1 }
          $p = Start-Process -FilePath $exe.FullName -ArgumentList "-Console" -WorkingDirectory $exe.DirectoryName -PassThru -RedirectStandardOutput rcc_out.txt -RedirectStandardError rcc_err.txt
          Start-Sleep -Seconds 12
          if ($p.HasExited) { Write-Error "RCCService exited early with code $($p.ExitCode)"; exit 1 }
          Stop-Process -Id $p.Id -Force
          Write-Host "SMOKE_OK: alive at T+12s"
```

Design notes: `-Console` starts the gSOAP accept loop and blocks forever by design (verified flags in RCCService/RCCService.cpp `_tmain`); "alive at T+12s" is the pass condition; early-exit fails loudly. Working directory = exe dir so content/ asset folder resolution behaves as installed.
